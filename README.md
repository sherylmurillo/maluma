# Generador CFG - Árbol de Derivación y AST

## Integrantes

* Sheryl Astrid Murillo Duque
* Mariana Andrea Escobar Bailarin

## Lenguaje

Python 3

## Librerías utilizadas

* nltk
* tkinter

## IDE utilizado

Visual Studio Code

## Descripción

Programa que permite ingresar una gramática libre de contexto (CFG) y una expresión, para generar:

* Derivación (izquierda o derecha)
* Árbol de derivación
* Árbol de sintaxis abstracta (AST)

## Ejecución

Instalar dependencia:

```bash
pip install nltk
```

Ejecutar el programa:

```bash
python main.py
```
